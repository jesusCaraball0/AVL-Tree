# Students Stored in AVL Tree
## Description
Using C++, the program implements a self balancing binary search tree known as an AVL tree to store student names and ID numbers. It includes all necessary logic such as insert, remove, find by ID, find by name, rebalancing, and printing by inorder, preorder, and postorder traversals. All inputs are tested for validity. 
## Install Instructions
There are no external dependencies, so the project can be forked and ran using an IDE, Makefile, or the terminal.
